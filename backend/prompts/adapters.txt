PROMPT ADAPTERS BACKEND

RESPONSABILIDAD DE ADAPTERS

- Acceder a datos de la BD chess_game.
- Traducir filas de base de datos a diccionarios.
- Ocultar si se usa SQL directo o ORM.
- Permitir que services no dependan de detalles de MariaDB.

Además debe tener dos implementaciones de acceso a datos:
- V1: SQL parametrizado sin ORM.
- V2: ORM con SQLAlchemy.


INTERFACES

UserAdapter.py
Define las operaciones necesarias para acceder a usuarios.

METODOS

find_by_id(user_id: int) -> dict | None
- Busca un usuario por id.

find_by_username(username: str) -> dict | None
- Busca un usuario por username.

find_credentials_by_username(username: str) -> dict | None
- Busca datos internos para autenticacion.
- Devuelve id, username y password_hash.
- No debe usarse para respuestas publicas.

save_user(request: UserCreateRequest) -> dict
- Guarda un usuario nuevo.

update_user(user_id: int, request: UserUpdateRequest) -> dict | None
- Actualiza un usuario.

delete_user(user_id: int) -> bool
- Borra un usuario.


GameAdapter.py
Define las operaciones necesarias para acceder a partidas.

METODOS

find_by_id(game_id: int) -> dict | None
- Busca una partida por id.

save_game(white_user_id: int, black_user_id: int) -> dict
- Guarda una partida nueva.

update_active_state(game_id: int, active: bool) -> dict | None
- Actualiza si una partida sigue activa.

delete_game(game_id: int) -> bool
- Borra una partida.


FileAdapter.py
Define operaciones de acceso a ficheros.

METODOS

read_text_file(file_name: str) -> str
- Lee un fichero de texto.
