Controladores backend para la version minima de auditoria.

Mantener:
- AuthenticationController: login y verificacion JWT.
- UserController: CRUD y busqueda de usuarios.
- GameController: listar, crear, consultar, mover y borrar partidas.

Endpoints principales:
- POST /authentication/login
- GET /authentication/verify
- POST /users
- GET /users/search
- GET /users/{user_id}
- PUT /users/{user_id}
- DELETE /users/{user_id}
- GET /games
- POST /games
- GET /games/{game_id}
- GET /games/{game_id}/board
- GET /games/{game_id}/state
- PUT /games/{game_id}/move
- DELETE /games/{game_id}

La comunicacion con el frontend debe ser exclusivamente REST.
