PROMPT MODELS BACKEND
Crea los POJO VACIOS de entrada y salida de la API. 
Estos modelos deben usar Pydantic BaseModel de FastAPI para separar la estructura de datos de la logica de los controladores.

RESPONSABILIDAD DE MODELS

- Definir la forma de los datos.
- Facilitar validacion automatica basica.
- Evitar repetir estructuras en los controladores.


AuthenticationModels.py
Este archivo contiene los modelos relacionados con autenticacion.

MODELS PREVISTOS

LoginRequest
- Representa los datos que recibe POST /authentication/login.
- Campos: username: str / password: str


UserModels.py
Este archivo contiene los modelos relacionados con usuarios.

MODELS PREVISTOS

UserCreateRequest
- Representa los datos que recibe POST /users.
- Campos: username: str / password: str

UserUpdateRequest
- Representa los datos que recibe PUT /users/{user_id}.
- Sus campos son opcionales porque se puede actualizar solo parte del usuario.
- Campos: username: str | None / password: str | None


GameModels.py
Este archivo contiene los modelos relacionados con partidas de ajedrez.

MODELS PREVISTOS
GameCreateRequest
- Representa los datos que recibe POST /games.
- Campos: white_user_id: int / black_user_id: int

MovementRequest
- Representa los datos que recibe PUT /games/{game_id}/move.
- Contiene coordenadas de origen y destino.
- Campos: from_x: int / from_y: int / to_x: int / to_y: int
